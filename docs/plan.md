# Portfolio position

This file is generated by sdk-forge/forge.py from the portfolio plan. Change the plan, not this
file: a hand edit here is never overwritten, but it stops the generator from updating the file
at all. Two documents govern this project and they govern different things: the obligation table
in [../ROADMAP.md](../ROADMAP.md) governs protocol work - which rows exist, and what evidence
closes one - and this file governs sequencing, which is which wave this project sits in, what
has to exist before it can ship behaviour, and what must not be started while it is unfinished.
[PORTFOLIO.md](../../PORTFOLIO.md) at the workspace root is the authority on both, so a change
to a tier, a wave or an arrow is made there and regenerated here, never the other way round.

## Position

**Tier 3, wave 3** - the routing-operations story. Tier 3 is planned: a solid gap with no
urgency, and better work once Tier 1 exists.

## Depends on

None. The portfolio plan puts no other project between this one and a first release: every
obligation in [../ROADMAP.md](../ROADMAP.md) is this repository's own, and nothing outside it
has to land first. That cuts both ways - a missing dependency is never the reason this project
has not shipped, and its wave position is the only thing holding it back.

## Sequencing rules

- At most two projects in the portfolio carry real effort at once. A third is not started, and
  no obligation is taken here, while those two are open.
- No new shell is created while any Tier 1 project still has an unimplemented obligation. The
  READMEs of the 27 generated shells are already the maintenance liability, and the failure mode
  of this portfolio is prose outrunning code rather than under-building.
- A project freezes to Tier 4 when its first release finds no external user, and a shell is
  retired publicly when a competitor ships what it promised rather than left to rot - the
  retirement is announced, not a README quietly left to go stale.

Protocol facts come from docs/rfc-map.md and the RFC Editor record, never from memory. This file
positions the work; it is not a source for anything a row cites.
